# User Stories - ANDO Web Management Portal

Este directorio va a ser cargado con las especificaciones detalladas de las **User Stories (US)** del proyecto web, divididas en archivos Markdown individuales para facilitar la trazabilidad y la implementación guiada por agentes de IA.

## Convención de Nombres
Utiliza la nomenclatura `US-[ID]-[Nombre].md`, por ejemplo:
* `US-02-Itinerario.md`
