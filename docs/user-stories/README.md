# User Stories - ANDO Web Management Portal

Este directorio contiene las especificaciones detalladas de las **User Stories (US)** del portal de gestión Web (`ando-web`), enfocadas exclusivamente en los roles de **Administrador** y **Prestador de Servicios**.

## Convención de Nombres
Utiliza la nomenclatura `US-[MODULO]-[ID].md`, por ejemplo:
* `ACC/US-ACC-01.md`
