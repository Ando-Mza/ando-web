# US-AYS-05: Reporte de Errores por el Usuario

## Información General
- **Identificador:** US-AYS-05
- **Actor:** Todos los tipos de Usuarios (Administrador / Prestador/ Turista)
- **Puntos de Historia:** 5
- **Precondiciones:**
  - El Usuario debe estar registrado en el sistema.
  - El Usuario debe iniciar sesión en el sistema.
- **Historias de Usuario Relacionadas:** US-GDU-01, US-GDU-02

---

## Descripción General
**Como** Usuario  
**Quiero** reportar errores encontrados en la plataforma Ando  
**Para** informar problemas y contribuir a la mejora del sistema.

---

## Descripción Funcional
El Usuario podrá reportar errores funcionales o visuales, permitiendo describir el problema y adjuntando capturas. El sistema identificará el reporte con un identificador para el seguimiento.

---

## Criterios de Aceptación
| Cuando | Espero | Pantalla |
| :--- | :--- | :--- |
| El Usuario completa los campos obligatorios | Que el sistema permita registrar el reporte | - |
| El Usuario envía el reporte | Que el sistema muestre un identificador de incidente | - |
| El Usuario deja campos vacíos | Que el sistema impida enviar el reporte | - |
| El Usuario envía el reporte | Que el sistema informe su seguimiento vía correo electrónico de la cuenta que reporta | - |
| El Usuario envía un reporte correctamente | El sistema muestra un cartel de confirmación “Reporte enviado correctamente” | - |
