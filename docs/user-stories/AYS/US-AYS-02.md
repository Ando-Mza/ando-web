# US-AYS-02: Preguntas Frecuentes FAQs

## Información General
- **Identificador:** US-AYS-02
- **Actor:** Todos los tipos de Usuarios (Administrador / Prestador/ Turista)
- **Puntos de Historia:** 2
- **Precondiciones:**
  - El Usuario debe estar registrado en el sistema.
- **Historias de Usuario Relacionadas:** US-AYS-01

---

## Descripción General
**Como** Usuario  
**Quiero** consultar preguntas frecuentes  
**Para** resolver dudas comunes sin necesidad de contactar soporte.

---

## Descripción Funcional
El sistema debe permitir la organización de las preguntas frecuentes por categorías para permitir que los Usuarios resuelvan sus dudas sobre el uso de Ando. Una vez que se encuentre la pregunta, se podrá expandir para analizar su respuesta o contraer para seguir viendo más preguntas.

---

## Criterios de Aceptación
| Cuando | Espero | Pantalla |
| :--- | :--- | :--- |
| El Usuario accede a la sección de preguntas frecuentes | Que el sistema muestre un listado de preguntas frecuentes | - |
| El Usuario selecciona una pregunta | Que el sistema despliegue la respuesta correspondiente | - |
| El Usuario realiza una búsqueda | Que el sistema filtre preguntas relacionadas | - |
| El Usuario seleccione contraer la pregunta | Que el sistema oculte la respuesta | - |
| El Usuario despliega más de una pregunta | Que el sistema mantenga abiertas las respuestas de las preguntas seleccionadas | - |
