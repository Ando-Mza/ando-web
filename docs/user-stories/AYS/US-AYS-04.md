# US-AYS-04: Tutoriales de Onboarding

## Información General
- **Identificador:** US-AYS-04
- **Actor:** Todos los tipos de Usuarios (Administrador / Prestador/ Turista)
- **Puntos de Historia:** 5
- **Precondiciones:**
  - El Usuario debe estar registrado en el sistema.
  - El Usuario debe iniciar sesión con su respectiva cuenta.
- **Historias de Usuario Relacionadas:** US-AYS-01

---

## Descripción General
**Como** Usuario  
**Quiero** acceder a tutoriales interactivos de onboarding  
**Para** aprender a utilizar correctamente las funcionalidades del sistema.

---

## Descripción Funcional
El sistema debe proveer tutoriales donde se definan los pasos y funciones incluidas en el sistema cuando se ingrese por primera vez. Los mismos deben presentar la opción de omitirse o repetirse. Su objetivo es ser una ayuda visual.

---

## Criterios de Aceptación
| Cuando | Espero | Pantalla |
| :--- | :--- | :--- |
| El Usuario ingrese por primera vez a la plataforma | Que el sistema muestre un tutorial onboarding | - |
| El Usuario avanza en el tutorial | Que el sistema muestre el paso explicativo | - |
| El Usuario finaliza el onboarding | Que el sistema muestre el mensaje “Tutorial completo ¿Desea repetirlo?” | - |
| El Usuario selecciona “Repetir” | Que el sistema inicie nuevamente el tutorial onboarding | - |
| El Usuario selecciona “Continuar” | Que el tutorial desaparezca de la pantalla | - |
| El Usuario omite el tutorial | Que el tutorial desaparezca de la pantalla | - |
